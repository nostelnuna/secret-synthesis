# 5~35인 시크릿 신세시스 (Secret Synthesis) : 연구소의 배신자

화학 시약 합성을 테마로 한 정통 정체 숨김 & 블러핑 심리 추리 보드게임 웹앱입니다.

---

## 🧪 게임 규칙 및 진행 방법

1. **진영 구분 (5~35인 자동 밸런스)**:
   * **수석 연구팀 (안정 진영)**: `🧪 안정 촉매 시약` 5개를 합성하거나, 스파이 수장을 강제 격리하면 승리!
   * **산업 스파이 (오염 진영)**: `☣️ 독성 반응물` 6개를 합성하거나, 독성 3개 이상 누적 시 **스파이 수장**을 실험담당자로 선출시키면 즉시 승리!

2. **시약 합성 심리전 (핵심 루프)**:
   * **지명 & 투표**: 매 라운드 연구책임자가 '실험담당자'를 지명하고, 전원이 찬반 신임 투표를 진행합니다. (연속 3번 부결 시 창고 맨 위 시약 1장이 무작위로 투입됩니다)
   * **시약 3장 → 2장 → 1장**: 연구책임자가 시약 3장을 뽑아 1장을 버리고 2장을 실험담당자에게 넘기면, 실험담당자가 최종 1장을 플라스크에 투입합니다.
   * **진실 공방**: 독성 시약이 나오면 책임자와 담당자 중 누가 거짓말을 했는지 채팅창에서 치열한 추리가 시작됩니다!

3. **독성 시약 누적 시 특수 능력 발동**:
   * **독성 1~2개**: 의심자 1명의 진영 비밀 감식 (수석 연구팀 vs 스파이)
   * **독성 3개**: 다음 라운드 연구책임자 특별 지명권
   * **독성 4~5개**: 의심자 1명 연구소 영구 강제 격리 (스파이 수장 제거 시 즉시 연구팀 승리!)

## 🚀 GitHub 및 Render.com 배포 방법 (1분)
1. `secret_synthesis_server.zip` 압축을 풉니다.
2. [GitHub.com](https://github.com)에 새 저장소(예: `secret-synthesis`)를 만들고 파일들을 업로드합니다.
3. [Render.com](https://render.com)에서 **[New +]** → **[Web Service]**로 연결하여 배포합니다.
4. 방장 관리자 비밀번호는 **`2146`** 입니다.
